这个站点没有后台、没有数据库，也没有服务器在运行。它是把一堆 Markdown 文件预先渲染成网页，再交给 GitHub 免费托管的结果。这篇文章记录它是怎么搭起来的，也当作这个站点的第一篇正式内容。

## 三个部件

整套东西只有三样：

1. **Hugo** —— 把 Markdown 和模板合成 HTML 的构建工具，单个可执行文件，不需要安装 Node、Python 或任何运行时。
2. **Git + GitHub** —— 存版本的地方。每次推送，等于给站点留了一个可以回退的快照。
3. **GitHub Actions + Pages** —— 前者的免费算力负责构建，后者负责把生成的文件分发到全球边缘节点。

## 一次发布的完整链路

写作之后的动作只有一条命令：

```sh
git add .
git commit -m "写完了"
git push
```

推送触发的流程是固定的：

- Actions 读取仓库，安装指定版本的 Hugo（当前固定为 `0.170.0`）；
- 执行 `hugo --minify`，把 `content/`、`layouts/`、`static/` 合成 `public/`；
- 把 `public/` 打包上传，交给 Pages 部署；
- 大约一分钟，线上就是新的内容。

## 为什么不用带后台的系统

> 静态站点的好处不是「更快」，而是「更少」。

少一层需要维护的运行时，就少一类故障：没有数据库连接池、没有 PHP 版本冲突、没有被扫描器打穿的插件。代价同样明确——评论、全文搜索、访问统计这些能力需要额外接第三方服务。

对一个人的写作站点来说，这笔交换是划算的。

## 之后写什么

这里会放三类东西：读书与文章的摘记、做东西时踩过的坑、以及还没想清楚但值得先写下来的念头。

写下来才算想过，这大概是这个地方存在的唯一理由。
